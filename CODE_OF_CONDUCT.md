# 📜 Code of Conduct | 社群行為準則

## 🌐 English (EN)
We are committed to providing a friendly, safe, and welcoming environment for all contributors and Bladers, regardless of age, background, identity, or skill level. Please maintain respectful, collaborative, and constructive discussions across all issues and pull requests.

## 🇭🇰 繁體中文 (ZH)
本專案致力於為所有陀螺同好（Bladers）、家長與開發者打造友善、包容且互相尊重的社群環境。所有討論與貢獻均應秉持友好、理性與建設性原則。
